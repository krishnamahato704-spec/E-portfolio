## Design decisions

Use original CSS inspired by Andreas's sentence-led hierarchy and Awwwards interaction references. No reference site's code, media or proprietary fonts are copied. Reuse the portfolio's licensed local Source Sans 3 and Source Serif 4. Use sticky numbered margins, fine rules, generous uneven spacing and a single high-contrast manifesto. Retain the existing photo gallery and film controls with their accessible behavior.
