# Portfolio loading and motion

The owner reports that the live page opening, scrolling and transitions feel uneven, and asks for code improvements using current supported techniques. Preserve the warm theme, original backgrounds, single muted film, five current published photographs, authentic teaching content, document access and Owner Studio.

Public pages must remain static and readable without a database request or JavaScript. Avoid a framework migration and new runtime dependencies. Keep reduced-motion, data-saving, keyboard, back/forward-cache and slow/offline fallbacks. New source changes require a local preview before publication; the previous approval covered the released warm version.

Acceptance:
- Delayed JavaScript must not start a full-screen opening after its startup budget has expired. Keep the short opening on prompt loads, with explicit music and skip.
- Opening crop motion must follow video frames using compositor movement, with clean callback cancellation; the background keeps one decoder.
- Load only the first Home photograph initially. Prepare the next image near rotation or on manual intent, preserving captions, owner removals, pause/focus and original viewers.
- Public routes load only the motion controllers they actually need. No animation makes visible reading content jump into position.
- Supported browsers use a brief native page crossfade; reduced-motion and unsupported browsers keep normal navigation. Prefetch only safe same-origin public page links on intent, with data-saving limits.
- Prioritise critical fonts/modules. Content-versioned local media can be cached safely without stale updates.
- Compare controlled before/after loading, layout-shift and frame measurements. Run existing content, media, recruiter, browser, accessibility and build checks, plus meaningful regressions for late startup, deferred image loading and navigation.

Backend review covers the existing public-data/build and authenticated owner paths. No schema, authentication, RLS, storage, live content, paid service or deployment change is authorised by this optimisation request.
