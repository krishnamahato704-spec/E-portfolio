# Oat, apricot, coral and Manrope

This records the preceding split-background iteration. The current full Teacher/Student scenes and larger typography are described in [DUAL_SCENE_REFINEMENT.md](DUAL_SCENE_REFINEMENT.md).

The owner rejected the dark blue and formal serif typography. This version uses a60/30/10 visual hierarchy with oat #F5F1E7 as the dominant ground, apricot #E4C5AF for secondary areas and coral #FF5738 for selected emphasis. The ratio guides visual balance; it is not a measured percentage of every pixel on the whole site.

The hero is light. Its apricot field occupies30percent of the stage width and moves to the opposite side in Student mode. The coral student-title strip, selected perspective and primary actions supply the loud accent. Apricot repeats through the photo spread, manifesto and footer. Quiet brown and rust contours replace the blue lines.

Manrope replaces the formal serif treatment and is used throughout the interface. Its variable200–800 file supports400 body text,500 labels and600–650 headings. Major headings use normal style. The existing CSS font tokens are retained for compatibility. The iris transition and curiosity lens remain connected to the same content and motion controls.

Body text is #24221F, secondary text #584D43, and links/focus #8F2D1B. Coral buttons and strips use dark text. The old explicit white file-size labels on primary resource buttons now inherit the dark parent text. Light photo scrims preserve dark-text readability over the decorative lens.
