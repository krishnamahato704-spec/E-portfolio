# Portfolio theme references

16 October 2026. The current cream, chocolate and copper appearance uses [Mentora's public preview](https://builder.hostinger.com/templates?preview=mentora) as a visual reference, following the owner's request. The palette mapping, scrim, component styling and responsive gallery adaptation were written in this repository. No Hostinger template source code, stock photographs, fonts, logos or sample content were imported. Hostinger's template redistribution rights have not been verified; this reference does not grant a reusable Hostinger template licence.

The preceding green version adapted **Botanical** (`botanical`) from the owner's shared local design-media library. Its source JSON/CSS hashes were verified before use; the prior reuse notice remains in [LIBRARY-REUSE.txt](../licences/LIBRARY-REUSE.txt). Historical captures remain separate from the current project style.

The current scheme is shared across all routes, the favicon and résumé accents. It preserves the existing illustrative background film, published photo compilation, selected original background illustrations and licensed typography. The gallery keeps a narrow cream photo border with readable light captions over a dark scrim. No external theme framework, font or media dependency is added. Save the current style only as a project-specific reference, separately from general reusable themes and without personal photographs or content.
